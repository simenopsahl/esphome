# Claude Code Instructions

This repository uses a platform-agnostic configuration standard.

Please refer to the primary instructions and architecture guidelines in **[AGENTS.md](AGENTS.md)**.

## Quick CLI Reference
- Validate config: `esphome config <device.yaml>`
- Compile config: `esphome compile <device.yaml>`
- Check board variants: Inspect `board/` and `board/pins/`
- Modular packages: Shared packages live in `common/`, `bluetooth/`, `features/`, and `gui/`
